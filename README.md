# Taathaal — Assam Craft Couture

A responsive e-commerce portfolio project for an Assam-based handmade craft label, built with HTML, CSS and JavaScript and designed for Firebase + Vercel deployment.

## Current frontend
- Responsive storefront
- Assamese craft collections: Mekhela Sador, Sarees, Gamusa and Fusion Accessories
- Search, category filters and sorting
- Product detail pages and reviews
- Wishlist
- Cart with stock limits and out-of-stock states
- Login/register demo flow
- Profile and order history
- Checkout flow
- Shop-owner/admin dashboard
- Order status processing
- Inventory and low/out-of-stock management
- Team and contact pages

## Planned online backend
Firebase Authentication, Firestore and optional Firebase Storage. Vercel will host the static frontend.

## Images
No AI-generated product imagery is used. Product images are sourced from the supplied project assets.

## Run locally
Open `index.html` with a local static server (recommended) or use VS Code Live Server.

## Note
The current account, order and admin data are demo/localStorage data. Firebase integration is the next stage.

## Payment demo
Taathaal supports two portfolio checkout methods without a payment gateway:
- Cash on Delivery (payment pending)
- Prepaid via manual UPI reference/UTR entry (verification pending until the shop owner confirms it)

The demo UPI ID shown in checkout is `taathaal@upi`. No real payment processing is performed.
